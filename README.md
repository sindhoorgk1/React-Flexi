# React Flexi Blog - Sistu Govatsa Krishna Sindhoor(2024501060)

A flexible React blog application built with Vite.

## Completed Challenges

The following challenges have been implemented in this project:

- **Challenge 1: Project Setup & Core Structure**
  - Initialized React + Vite project.
  - Setup ESLint and basic project structure.

- **Challenge 2: View Posts**
  - Implementation of `BlogPostList` to display all blog posts.

- **Challenge 3: Create & Edit Posts**
  - `CreatePostPage` and `EditPostPage` for managing content.
  - `BlogPostForm` reusable component.

- **Challenge 4: Delete Posts**
  - Implementation of `DeleteButton` with `ConfirmationDialog`.

- **Challenge 5: Responsive Navigation & Layout**
  - Created `NavBar` and `Layout` components.
  - Implemented responsive styles with mobile hamburger menu.
  - Integrated `react-router-dom` for navigation.

- **Challenge 6: Comment System**
  - Created `Comment`, `CommentList`, and `CommentForm` components.
  - Integrated comments into `BlogPostDetail`.

- **Challenge 7: Search Functionality**
  - Implemented `SearchBar` with responsive design.
  - Added filtering logic for posts by title and content.

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`
